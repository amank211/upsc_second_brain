Created two companion reference docs (new-doc-in-drafts workflow), **promoted 2026-08-25** from `drafts/GS2/` to `notes/GS2/` under a blanket "approve all" instruction (see [[feedback_draft_promotion_batching]]); draft copies deleted:

- **International Groups.md** — informal forums/groupings: G7, G20, BRICS, G4, NAM, SCO, QUAD, ASEAN, G77, I2U2. Each entry has Overview / History / Goals-Ambition / Recent Activity-Conflict, color-coded (teal theme, red box for the conflict section).
- **International Organisations.md** — formal treaty-based bodies: UN (with UNSC/UNGA/ICJ/ECOSOC/Secretariat detail), World Bank, IMF, WHO, WTO, UNESCO, ILO. Each entry adds a Structure & Governance section (dominant countries/voting shares, leadership, internal bodies) between History and Recent Activity (indigo theme).

**Research method:** used WebSearch/WebFetch restricted to the vault's approved UPSC source set (`drishtiias.com`, `visionias.in`, `vajiramandravi.com`, `pib.gov.in`, `mea.gov.in`) per [[feedback_upsc_source_restriction]] — this was the first time that restriction was applied to a general-reference (non-book, non-policy) research task, confirming the restriction covers "research X for UPSC" broadly, not just `notes/GS2/policy/*.md`.

**Why:** the user wanted every fact traceable and current (dominant voting shares, current leadership names, 2025–26 events like the US WHO/UNESCO withdrawals, WTO Appellate Body paralysis, BRICS 2024–25 expansion) — this is fast-moving content that needs periodic refresh, unlike the static Pax Indica book notes.

**How to apply:** these two docs will go stale faster than book-derived notes (leadership changes, membership changes, new summits/conflicts). If asked to "update" or "refresh" these later, re-run the same restricted-domain searches per entity rather than assuming the drafted facts are still current. Also see [[project_pax_indica_draft_state]] for the sibling book-notes project running in parallel in this vault.
