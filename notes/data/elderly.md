<h2 style="background-color:#2c3e50; color:#ffffff; padding:10px 16px; border-radius:6px;">Elderly — Key Data</h2>

<p style="font-size:1.1em; color:#6b6b6b; margin:20px 0 10px 0; font-weight:800; text-transform:uppercase; letter-spacing:1px;">Demographics &amp; Projections</p>

<p style="font-size:0.72em; color:#aaaaaa; margin:8px 0 0 0; font-style:italic;">Source: UNFPA India Ageing Report 2023</p>
