<h2 style="background-color:#2c3e50; color:#ffffff; padding:10px 16px; border-radius:6px;">Poverty &amp; Hunger — Key Data</h2>

<p style="font-size:1.1em; color:#6b6b6b; margin:20px 0 10px 0; font-weight:800; text-transform:uppercase; letter-spacing:1px;">Poverty Alleviation Schemes</p>
<div style="display:flex; flex-direction:column; gap:12px;">

<div style="background-color:#ffffff; border:1px solid #e2e2e2; border-top:4px solid #2c7a6b; border-radius:8px; padding:14px;">
<div style="font-weight:600; font-size:1.05em;">MGNREGA Guaranteed Employment</div>
<div style="font-size:1.6em; font-weight:bold; color:#2c7a6b; margin-top:4px;">100 days/year</div>
<p style="font-size:0.88em; color:#555555; margin:6px 0 0 0;">MGNREGA guarantees at least one adult member of a rural household employment for a minimum of 100 days per year.</p>
<p style="font-size:0.72em; color:#aaaaaa; margin:8px 0 0 0; font-style:italic;">Source: as provided (not independently verified this session)</p>
</div>

</div>

<p style="font-size:1.1em; color:#6b6b6b; margin:24px 0 10px 0; font-weight:800; text-transform:uppercase; letter-spacing:1px;">Progress in Poverty Reduction</p>
<div style="display:flex; flex-direction:column; gap:12px;">

<div style="background-color:#ffffff; border:1px solid #e2e2e2; border-top:4px solid #2c7a6b; border-radius:8px; padding:14px;">
<div style="font-weight:600; font-size:1.05em;">People Lifted Out of Poverty <span style="font-weight:400; color:#999999; font-size:0.8em;">(2015–16 to 2019–21)</span></div>
<div style="font-size:1.6em; font-weight:bold; color:#2c7a6b; margin-top:4px;">13.5 crore</div>
<p style="font-size:0.88em; color:#555555; margin:6px 0 0 0;">According to NITI Aayog's Multidimensional Poverty Index (MPI) report, 13.5 crore people were lifted out of poverty between 2015–16 and 2019–21.</p>
<p style="font-size:0.72em; color:#aaaaaa; margin:8px 0 0 0; font-style:italic;">Source: NITI Aayog MPI Report, as cited (not independently verified this session)</p>
</div>

<div style="background-color:#ffffff; border:1px solid #e2e2e2; border-top:4px solid #2c7a6b; border-radius:8px; padding:14px;">
<div style="font-weight:600; font-size:1.05em;">National (Multidimensional) Poverty Rate</div>

</tr>
<tr>
<td style="padding:0 8px 0 0; font-size:1.15em; font-weight:bold; color:#c0392b;">24.85%</td>
<td style="padding:0; font-size:1.15em; font-weight:bold; color:#2c7a6b;">14.96%</td>
</tr>
</table>
<p style="font-size:0.88em; color:#555555; margin:8px 0 0 0;">India's national poverty rate declined from 24.85% (2015–16) to 14.96% (2019–21), with the decline more pronounced in rural areas.</p>
<p style="font-size:0.72em; color:#aaaaaa; margin:8px 0 0 0; font-style:italic;">Source: NITI Aayog MPI Report, as cited (not independently verified this session)</p>

<p style="font-size:0.88em; color:#555555; margin:8px 0 0 0;"><b>Lived reality (2022–2025):</b> the World Bank poverty line is ₹62/day (PPP), yet 83% of Indians live below ₹171/day (based on the $8.40 PPP line); the top 1% owns 40.1% of wealth (World Inequality Database) — pointing to rising vulnerability even as headline poverty rates fall.</p>

<p style="font-size:1.1em; color:#6b6b6b; margin:24px 0 10px 0; font-weight:800; text-transform:uppercase; letter-spacing:1px;">Hunger &amp; Nutrition Schemes</p>
<div style="display:flex; flex-direction:column; gap:12px;">

<div style="background-color:#ffffff; border:1px solid #e2e2e2; border-top:4px solid #c0392b; border-radius:8px; padding:14px;">
<div style="font-weight:600; font-size:1.05em;">National Food Security Act (NFSA) Coverage</div>
<div style="font-size:1.6em; font-weight:bold; color:#c0392b; margin-top:4px;">~81 crore people</div>
<table style="width:100%; border-collapse:collapse; margin-top:8px;">
<tr>
<td style="padding:2px 8px 2px 0; color:#999999; font-size:0.78em;">Rural Population Targeted</td>
<td style="padding:2px 0; color:#999999; font-size:0.78em;">Urban Population Targeted</td>
</tr>
<tr>
<td style="padding:0 8px 0 0; font-size:1.15em; font-weight:bold; color:#c0392b;">75%</td>
<td style="padding:0; font-size:1.15em; font-weight:bold; color:#c0392b;">50%</td>
</tr>
</table>
<p style="font-size:0.88em; color:#555555; margin:8px 0 0 0;">NFSA covers around 81 crore people, targeting 75% of the rural population and 50% of the urban population, providing subsidized food grains through the Targeted Public Distribution System (TPDS).</p>
<p style="font-size:0.72em; color:#aaaaaa; margin:8px 0 0 0; font-style:italic;">Source: as provided (not independently verified this session)</p>
</div>

<div style="background-color:#ffffff; border:1px solid #e2e2e2; border-top:4px solid #c0392b; border-radius:8px; padding:14px;">
<div style="font-weight:600; font-size:1.05em;">PMGKAY Beneficiaries <span style="font-weight:400; color:#999999; font-size:0.8em;">(extended till 2029)</span></div>
<div style="font-size:1.6em; font-weight:bold; color:#c0392b; margin-top:4px;">81.35 crore</div>
<p style="font-size:0.88em; color:#555555; margin:6px 0 0 0;">Pradhan Mantri Garib Kalyan Anna Yojana (PMGKAY) ensures free food grains to 81.35 crore beneficiaries, and has been extended till 2029, acting as a buffer for the poor against economic shocks.</p>
<p style="font-size:0.72em; color:#aaaaaa; margin:8px 0 0 0; font-style:italic;">Source: as provided (not independently verified this session)</p>
</div>

<div style="background-color:#ffffff; border:1px solid #e2e2e2; border-top:4px solid #c0392b; border-radius:8px; padding:14px;">
<div style="font-weight:600; font-size:1.05em;">POSHAN Abhiyaan — Jan Andolan Reach</div>
<div style="font-size:1.6em; font-weight:bold; color:#c0392b; margin-top:4px;">30 crore+</div>
<p style="font-size:0.88em; color:#555555; margin:6px 0 0 0;">POSHAN Abhiyaan's Jan Andolan (community mobilization) campaigns have reached over 30 crore people to spread nutrition awareness, and the mission integrates efforts across 18 ministries.</p>
<p style="font-size:0.72em; color:#aaaaaa; margin:8px 0 0 0; font-style:italic;">Source: as provided (not independently verified this session)</p>
</div>

</div>

<p style="font-size:1.1em; color:#6b6b6b; margin:24px 0 10px 0; font-weight:800; text-transform:uppercase; letter-spacing:1px;">Multidimensional Poverty Index (MPI)</p>
<div style="display:flex; flex-direction:column; gap:12px;">

<div style="background-color:#ffffff; border:1px solid #e2e2e2; border-top:4px solid #4a6b7c; border-radius:8px; padding:14px;">
<div style="font-weight:600; font-size:1.05em;">Multidimensional Poverty &amp; Vulnerability <span style="font-weight:400; color:#999999; font-size:0.8em;">(2025 Human Development Report)</span></div>
<table style="width:100%; border-collapse:collapse; margin-top:8px;">
<tr>
<td style="padding:2px 8px 2px 0; color:#999999; font-size:0.78em;">Multidimensionally Poor</td>
<td style="padding:2px 8px 2px 0; color:#999999; font-size:0.78em;">In Severe Poverty</td>
<td style="padding:2px 0; color:#999999; font-size:0.78em;">Vulnerable to Poverty</td>
</tr>
<tr>
<td style="padding:0 8px 0 0; font-size:1.15em; font-weight:bold; color:#4a6b7c;">16.4%</td>
<td style="padding:0 8px 0 0; font-size:1.15em; font-weight:bold; color:#4a6b7c;">4.2%</td>
<td style="padding:0; font-size:1.15em; font-weight:bold; color:#4a6b7c;">18.7%</td>
</tr>
</table>
<p style="font-size:0.88em; color:#555555; margin:8px 0 0 0;">Per the 2025 Human Development Report, 16.4% of Indians are multidimensionally poor, 4.2% are in severe poverty, and a further 18.7% are vulnerable to falling into poverty.</p>
<p style="font-size:0.72em; color:#aaaaaa; margin:8px 0 0 0; font-style:italic;">Source: 2025 Human Development Report, as cited (not independently verified this session)</p>
</div>

<div style="background-color:#ffffff; border:1px solid #e2e2e2; border-top:4px solid #2c7a6b; border-radius:8px; padding:14px;">
<div style="font-weight:600; font-size:1.05em;">People Who Escaped Poverty <span style="font-weight:400; color:#999999; font-size:0.8em;">(15 years, national MPI)</span></div>
<div style="font-size:1.6em; font-weight:bold; color:#2c7a6b; margin-top:4px;">~415 million</div>
<p style="font-size:0.88em; color:#555555; margin:6px 0 0 0;">About 415 million people escaped multidimensional poverty in India over 15 years, per the national MPI (based on NFHS-5, 2019–21).</p>
<p style="font-size:0.72em; color:#aaaaaa; margin:8px 0 0 0; font-style:italic;">Source: National MPI, as cited (not independently verified this session)</p>
</div>

<div style="background-color:#ffffff; border:1px solid #e2e2e2; border-top:4px solid #2c7a6b; border-radius:8px; padding:14px;">
<div style="font-weight:600; font-size:1.05em;">Urban Poverty Rate <span style="font-weight:400; color:#999999; font-size:0.8em;">(national MPI, 2019–21)</span></div>
<div style="font-size:1.6em; font-weight:bold; color:#2c7a6b; margin-top:4px;">5.5%</div>
<p style="font-size:0.88em; color:#555555; margin:6px 0 0 0;">Urban multidimensional poverty stands at 5.5%. Rural areas and poorer states like Bihar, Jharkhand, and Uttar Pradesh saw the fastest reductions but still have high absolute numbers of poor.</p>
<p style="font-size:0.72em; color:#aaaaaa; margin:8px 0 0 0; font-style:italic;">Source: National MPI, as cited (not independently verified this session)</p>
</div>

<div style="background-color:#ffffff; border:1px solid #e2e2e2; border-top:4px solid #c0392b; border-radius:8px; padding:14px;">
<div style="font-weight:600; font-size:1.05em;">MPI Deprivation from Schooling</div>
<div style="font-size:1.6em; font-weight:bold; color:#c0392b; margin-top:4px;">11.9%</div>
<p style="font-size:0.88em; color:#555555; margin:6px 0 0 0;">11.9% of the MPI deprivation is attributed to years of schooling — cited as a target area for improving rural digital access and NEP 2020 implementation.</p>
<p style="font-size:0.72em; color:#aaaaaa; margin:8px 0 0 0; font-style:italic;">Source: as provided (not independently verified this session)</p>
</div>

<div style="background-color:#ffffff; border:1px solid #e2e2e2; border-top:4px solid #c0392b; border-radius:8px; padding:14px;">
<div style="font-weight:600; font-size:1.05em;">Agricultural Dependence in MPI-Intense Districts</div>
<div style="font-size:1.6em; font-weight:bold; color:#c0392b; margin-top:4px;">45%</div>
<p style="font-size:0.88em; color:#555555; margin:6px 0 0 0;">45% agri-dependence in MPI-intense districts is cited as a target for rural livelihood diversification through skilling, MSMEs, and allied sectors.</p>
